# 世界のちいさな村

低ポリ3Dの箱庭で、国球たちを迎えながら村を育てる小さなゲームです。

## 開発

```bash
npm install
npm run dev
```

テストとproduction buildは次のコマンドで実行できます。

```bash
npm test
npm run lint
npm run build
```

Cloudflare Pagesでは、ビルドコマンドを `npm run build`、出力ディレクトリを `dist` に設定してください。

## 操作

- ドラッグ：カメラをパン
- ホイール：ズーム
- 「建築」から建物を選び、村のセルをクリック：配置
- 配置済みの建物をクリック：移動・撤去
- 住民をクリック：現在の状態を表示
- 「建築」から1マスの「畑」を配置（1つ10コイン）
- 「作物」で小麦かトマトの種を選び、空の畑をタップ・スワイプ：選んだ種を1個使って種まき
- 成熟した作物を村画面でタップ：作物1個と同じ作物の種2個を収穫
- 小麦は10秒で緑、さらに10秒で茶色の成熟状態へ変化
- トマトは10秒で緑のツル、さらに10秒で赤い実がなる成熟状態へ変化
- 「建築」の「自然」から1マスの「牛」を配置（1頭50コイン）
- 30秒後に牛乳マークが出た牛をタップ：牛乳を2個収穫
- 「建築」の「建物」から1マスの「牛乳工場」を配置（1つ80コイン）
- 未設定の牛乳工場をタップし、バターかチーズを選択：以後20秒ごとに牛乳1個を消費して選んだ加工物を3個自動生産
- 「建築」の「自然」から1マスの「豚」を配置（1頭50コイン）
- 30秒後に豚肉マークが出た豚をタップ：豚肉を2個収穫（豚はそのまま残ります）
- 「建築」の「自然」から1マスの「鶏」を配置（1羽50コイン）
- 30秒後に卵マークが出た鶏をタップ：卵を2個収穫（鶏はそのまま残ります）
- 「建築」の「建物」から1マスの「豚肉工場」を配置（1つ80コイン）
- 未設定の豚肉工場をタップし、ハム・ソーセージ・ベーコンから選択：以後20秒ごとに豚肉1個を消費して選んだ加工物を3個自動生産
- 「建築」の「建物」から「ピザ屋」を配置し、選択後に「ピザを作る」：ピザを選び、数量入力または「10個」ボタンで生産数と消費材料を確認して作成
- ピザ1枚につきベーコン1個・チーズ1個・トマト1個・小麦2個を消費
- ピザがある時だけ他地域の来訪客がピザ屋に並び、1枚販売するごとに3コインを獲得
- 「作物」メニューの素材・加工物欄で、卵・牛乳・豚肉・各加工物・ピザの所持数を確認

ゲーム状態はブラウザのlocalStorageへ自動保存されます。
